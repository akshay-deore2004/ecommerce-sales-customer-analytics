# E-Commerce Sales & Customer Analytics

## Project Overview

This project performs exploratory data analysis on a synthetic e-commerce dataset to understand sales performance, customer spending, product revenue, city-wise sales, category performance, and payment methods.

The project was developed using Python, Pandas, Matplotlib, and Jupyter Notebook.

## Objectives

- Calculate total revenue and number of orders.
- Analyze sales by product.
- Compare sales across different cities.
- Analyze customer spending patterns.
- Analyze sales by product category.
- Examine revenue by payment method.
- Create visualizations to communicate business insights.

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- CSV

## Dataset

The project uses a small synthetic dataset containing **20 sample e-commerce orders**.

The dataset is created for learning and portfolio demonstration purposes and does not represent real company transactions.

## Key Results

- **Total Orders:** 20
- **Total Revenue:** ₹188,500
- **Unique Customers:** 10
- **Highest-Revenue Product:** Laptop
- **Highest-Revenue City:** Pune

## Analysis Performed

### 1. Sales by Product

Analyzed total revenue generated by each product.

### 2. Sales by City

Compared revenue across Pune, Mumbai, and Nashik.

### 3. Customer Spending

Calculated total spending for each customer and identified high-spending customers.

### 4. Sales by Category

Analyzed revenue across:

- Electronics
- Clothing
- Footwear
- Accessories

### 5. Payment Method Analysis

Compared sales generated through different payment methods such as UPI, Card, and Cash.

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/akshay-deore2004/ecommerce-sales-customer-analytics.git
```

### 2. Open the project folder

```bash
cd ecommerce-sales-customer-analytics
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Run the sales analysis

```bash
python src/analyze_sales.py
```

### 5. Generate product sales visualization

